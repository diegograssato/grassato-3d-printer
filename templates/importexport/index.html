    Importar dados (CSV / ZIP)

    Envie um arquivo .csv (um tipo por arquivo) ou um .zip contendo múltiplos CSVs. O tipo é detectado automaticamente pelo cabeçalho.
    A importação respeita a ordem: Fornecedores → Filamentos → Produtos, garantindo a integridade dos vínculos.

    {% csrf_token %}
    Registros existentes (mesmo nome/identificador) serão atualizados. Fornecedores e Filamentos ausentes na base serão criados automaticamente quando referenciados.

    Regras de atrelamento na importação:

    • Filamentos → vinculados ao fornecedor pelo campo fornecedor_nome (criado se não existir).
    • Produtos → vinculados ao filamento pelo conjunto filamento_nome + filamento_cor + filamento_material (deve existir).
    • Use exportar primeiro para obter modelos de CSV com o formato correto.
